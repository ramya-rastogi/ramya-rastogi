### 🔬 [Aurea — Research, Reimagined](https://github.com/ramya-rastogi/Aurea-Research-Reimagined.)

**A multi-agent AI research pipeline. Topic in → structured report out.**

Four specialized agents work in sequence: **Search → Read → Write → Critique** — delivering a fully sourced, self-reviewed research report in minutes. No Googling. No blank-page paralysis. Just results.

> 🔴 Live → [aurea-research-reimagined.streamlit.app](https://aurea-research-reimagined.streamlit.app/)

`Python` `LangChain` `Streamlit` `Multi-Agent AI` `Web Scraping`

---

### 📚 [BookBuddy — Chat with Any PDF](https://github.com/ramya-rastogi/BookBuddy)

**Upload a PDF. Ask a question. Get answers — directly from the book.**

A local RAG app built with LangChain + Mistral AI + ChromaDB. Uses semantic search with MMR retrieval to surface diverse, relevant passages from textbooks, papers, or manuals. Persistent vector store means no re-processing on every run.

`Python` `LangChain` `Mistral AI` `ChromaDB` `HuggingFace Embeddings` `RAG` `Streamlit`

---

### 🎬 [CineSnap — Movie Info Extractor](https://github.com/ramya-rastogi/CineSnap)

**Paste a paragraph. Get a movie's soul, structured.**

Drop any unstructured movie description — a blog post, a review, a WhatsApp message — and CineSnap extracts title, genre, cast, director, year, and a clean summary as validated JSON. Powered by Mistral AI + Pydantic output parsing.

`Python` `LangChain` `Mistral AI` `Pydantic` `Structured Output`

---

### 🔌 [EVision — Smart EV Innovation Analyzer](https://github.com/ramya-rastogi/EVision)

**A data-driven platform that scores electric vehicles on innovation — objectively.**

Built a composite Innovation Score (0–100) across 360+ EV models using a weighted formula covering Tech Edge, Energy Intelligence, and User Value. Trained a Linear Regression model with **R² = 0.99**, paired with a Gemini AI assistant for natural language EV queries.

`Python` `Pandas` `scikit-learn` `Streamlit` `Gemini AI` `ML` `EDA`

---

### ✈️ [Itinerary Genie — AI Travel Planner](https://github.com/ramya-rastogi/itineraray-genie)

**Tell it where you want to go. It handles the rest.**

An AI-powered travel itinerary generator backed by **Google Gemini + n8n automation**. It takes your destination, budget, and vibe — then emails you a fully structured itinerary, hands-free. Workflow: Webhook → Sheets → AI Agent → Gmail.

> 🔴 Live → [ai-trip-orchestrator.lovable.app](https://ai-trip-orchestrator.lovable.app)

`n8n` `Google Gemini` `Webhooks` `Google Sheets` `Gmail API` `Automation`

---

### 💊 [MedoKnow — Medical Knowledge Platform](https://github.com/ramya-rastogi/medoknow)

**Medicine lookup that doesn't make you Google three more things.**

An interactive browser-based tool covering 20+ essential medicines — composition, brands, uses, side effects, and precautions — with a Vanta.js animated UI and zero dependency on external APIs.

`HTML` `CSS` `JavaScript` `Vanta.js`

### 🏏 [IPL 2025 Batters Analysis](https://github.com/ramya-rastogi/IPL-2025-Batters-Analysis)
